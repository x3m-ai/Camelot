# OWASP MASTG + Hacking Playground — Content (Camelot CDN)

Source-faithful OWASP MAS / MASTG + MASTG Hacking Playground content for
Morgana Mobile Lab. Generated by `morgana/excalibur/tools/convert_mastg.py`.

- Source units discovered: 292 tests (163 Android / 129 iOS), 157 demos,
  141 knowledge, 168 techniques, 136 tools, 30 apps, 75 best practices
- Published test Scripts: 292 (manual procedure cards, never fake automation)
- Published demo Scripts: 157 (23 executable Frida, 134 manual reference)
- Packages: 4 (`mastg-tests-{android,ios}-v1`, `mastg-demos-{android,ios}-v1`)
- Hacking Playground: 3 App Assets + 1 Rails backend Supporting Service
- Validation: PASS (100% test/demo reconciliation, zero silent loss)

## Semantic model

- **MASTG Tests are NOT blindly converted into Scripts.** They are manual
  procedure cards classified MANUAL / SEMI_AUTOMATABLE / AUTOMATABLE.
- **Only real executable demos become Scripts.** Frida JavaScript demos use the
  `frida` executor; radare2 / semgrep / ADB / sample-code demos are manual
  references.
- **Hacking Playground apps are Mobile Lab App Assets**, not Scripts.

## Layout

| Path | Content |

| `demos/*.json` | MASTG demo packs (Frida exec + manual reference) |

| `mastg-test-inventory.json` | per-test discovery + conversion status |

| `coverage/mastg-coverage.json` | MASTG tests + demos + MASVS rollup (CDN) |
| `apps/owasp-playground-apps.json` | Hacking Playground app/service index |
